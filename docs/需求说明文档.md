# 《熄灯前归寝》需求说明

## 一、功能性需求

### 1.1 游戏概述

《熄灯前归寝》是一款依托 Zuul 文本冒险游戏基础架构二次开发的校园主题文字冒险游戏。玩家需要在每晚 23:00 校园熄灯时限到来之前，从学校大门出发，穿梭校园各个楼宇场景，集齐全部归寝必备凭证，最终顺利返回寝室完成就寝通关。游戏一共设置五个递进式关卡，随着关卡逐步推进，游戏可探索地图范围持续扩大，解谜环节难度逐步提升，场景干扰信息也会不断增多，整体形成由浅入深、循序渐进的闯关游玩体验。

### 1.2 房间、物品与信息查看机制

整个游戏世界由多个互通互联的房间场景搭建而成，每一个房间均可存放不限数量的游戏物品。所有物品统一包含名称、负重、详细背景介绍三类基础属性；同时每个房间支持展示专属公告内容，公告分为固定场景提示文案以及随关卡动态变化的剧情解谜线索两类，为玩家闯关提供指引。

玩家进入任意房间后，可通过对应指令查看场景各类信息：输入 `look` 指令，可查看当前房间场景描述、房间公告、场景出入口以及场内所有物品；输入 `items` 指令，可查看当前房间物品、个人背包内全部物品以及角色实时负重状态；输入 `inspect` 指令，可查看背包内单个物品的完整详情介绍。系统需要保障所有展示信息完整无误、数据实时同步，依托完整的场景信息支撑玩家做出合理的闯关决策。

### 1.3 移动、回退与特殊房间规则

玩家可通过方向指令实现不同房间之间的场景移动，系统会全程记录玩家完整的房间访问轨迹，依托访问记录提供 `back` 回退指令，支持玩家返回上一间房间。若玩家处于初始起点、无可用回退场景时，系统需要弹出清晰的中文提示告知玩家无法回退。同时支持连续多次执行 `back` 指令，玩家可一路回退至当前关卡的起点校门。

游戏第五关设置专属特殊随机传送房间——体育馆，玩家进入该场景后，将会被随机传送至除寝室、图书馆之外的所有已解锁开放房间内。该传送机制仅在第五关生效，传送过程不会消耗游戏倒计时时长；若随机传送后的目标房间存在准入限制，系统依旧会按照原有房间准入规则拦截玩家，不会因传送机制破例放行。

| 房间类型 | 生效关卡 | 行为说明 |
|----------|----------|----------|
| 普通房间 | 全关卡 | 玩家可通过出口指令正常自由移动，无任何额外限制 |
| 条件门房间 | 图书馆、寝室 | 需要满足刷卡、凭证提交等前置条件方可进入 |
| 断电房间 | 第三、四关主楼 | 角色未携带手电筒时，无法进入该场景 |
| 困锁房间 | 第三关起西楼 | 玩家进入房间后，东侧出口会自动锁定，无法直接原路离开 |
| 传送房间 | 第五关体育馆 | 触发随机传送机制，将玩家转移至其余已开放房间 |

### 1.4 玩家属性、负重规则与食物系统

游戏内置 Player 玩家对象，统一管理角色姓名、当前所在场景、背包物品清单三大核心信息。角色背包存在固定负重上限，当拾取物品后总负重超出上限时，系统将自动拦截拾取操作，并同步给出超重提示，阻止玩家继续拾取物品。

游戏内所有食物统一通过 `eat` 指令食用，支持两种食用方式：玩家直接输入 `eat`，可自动食用背包内第一个可食用物品；也可在指令后补充物品名称，定向食用指定食物。游戏可食用物品包含魔法饼干、火腿肠、奶茶、辣椒包、外卖等品类。所有食物食用基础耗时固定为 25 秒，其中奶茶存在专属负面效果，食用后额外增加 30 秒拉肚子罚时；其余普通食物主要作用为占用背包负重、干扰玩家闯关节奏，无额外时间增减效果。

魔法饼干为游戏核心功能性食物，具备双重增益效果：每一关内首次食用，可为玩家补充 300 秒闯关时长，同时永久提升角色背包负重上限；同一关卡内重复食用，不再触发时长加成效果。该物品拥有两种获取途径：一是从第三关开始，系统会在博学主楼、博学东楼、越苑食堂三个场景中随机一处刷新魔法饼干；二是从第四关开始，玩家可前往博学北楼，使用火腿肠投喂猫学长兑换获取魔法饼干。

从第二关开始，食堂场景会固定刷新火腿肠。猫学长尚未登场的前三关，玩家可直接食用背包内的火腿肠；第四关猫学长正式现身后，系统才会开放 `feed` 投喂指令。前三关全程无喂猫相关功能，系统不会注册该指令，游戏帮助界面、操作提示面板中也不会展示该指令相关内容。

### 1.5 五关流程与通关条件

游戏五个关卡均围绕熄灯限时归寝核心主题设计，但各关卡开放地图范围、必备通关凭证、最终过关要求均存在差异化设定。每一关开局都会重置游戏状态：玩家统一从校门起点出发，背包物品全部清空，房间物品、场景公告均按照当前关卡配置重新生成。所有关卡统一以在寝室场景执行 `sleep` 指令作为最终通关操作。

| 关卡 | 开放范围 | 核心目标 | 过关条件 |
|------|----------|----------|----------|
| 第一关 | 5 个房间 | 熟悉基础游戏操作与一卡通兑换流程 | 持有一卡通，前往寝室执行 `sleep` 指令 |
| 第二关 | 7 个房间 | 新增归寝单机制，拓展校园场馆探索内容 | 持有一卡通，完成凭证 `submit` 提交操作后，执行 `sleep` 指令 |
| 第三关 | 9 个房间 | 解锁主楼断电限制、西楼密室解谜玩法 | 获取手电筒、完成西楼密室解谜，集齐双凭证并完成 `submit` 提交，最后执行 `sleep` 指令 |
| 第四关 | 10 个房间 | 开放图书馆凭证领取玩法，新增可选喂猫支线 | 兑换一卡通后进入图书馆领取归寝单，完成 `submit` 提交后执行 `sleep` 指令 |
| 第五关 | 10 个房间 | 全地图探索，新增寝室智能锁密码解谜 | 解锁寝室智能锁，集齐双凭证并完成 `submit` 提交，最终执行 `sleep` 指令通关 |

第一关为新手教学关卡，流程最简单：玩家前往北楼拾取现金，前往教育超市兑换一卡通，随后直接进入寝室就寝即可，本关无需获取归寝单。

从第二关开始，归寝单成为通关必备凭证。玩家除准备一卡通之外，还需要提前获取归寝单，前往教育超市门口寝室通道执行 `submit` 提交指令，提交完成后方可进入寝室。第二、三关归寝单由北楼志愿者发放；第四关起归寝单发放点位变更为图书馆，北楼志愿者仅负责文字指引，提示玩家前往图书馆领取凭证。若玩家提交错误物品（如赛事纪念帽），系统将直接判定当前关卡闯关失败。

第三关是全游戏解谜核心关卡，博学主楼在第三、四关全程断电，玩家无手电筒强行进入，会被扣除一分钟时长并强制退回上一房间。玩家需要先前往体育馆拾取手电筒，再进入西楼完成物品合成与砸锁脱困解谜。玩家进入西楼后会自动触发房间困锁机制，东侧出口永久封锁，必须收集棍子、石头、绳子三样材料，合成锤子并使用后方可离开西楼。

第四关正式开放图书馆场景，玩家必须先兑换一卡通，才能获得图书馆准入资格并领取归寝单。本关北楼刷新猫学长 NPC，玩家可自主选择投喂火腿肠兑换魔法饼干，该支线为可选玩法，不影响主线通关流程。

第五关为游戏终章关卡，玩家需要查看图书馆内公告记载的校史线索，推理出寝室智能锁正确密码 20000527，在寝室场景执行 `unlock` 指令解锁门锁，补齐双凭证并完成提交操作后，执行 `sleep` 指令即可完成全游戏通关。食堂纸条标注的 2026.06.01 仅为干扰信息，无法用于解锁寝室门锁。

### 1.6 拓展命令与 NPC 交互规则

除基础移动、物品查看指令外，游戏配套多组拓展指令，支撑五关完整主线流程：`use` 指令用于超市换卡、西楼砸锁、图书馆盖章等物品使用操作；`submit` 指令专门用于归寝单凭证提交；`combine` 指令用于西楼场景锤子材料合成；`unlock` 指令用于体育馆器材室门锁、第五关寝室智能锁解锁；`talk` 与 `register` 指令用于和宿管、志愿者、图书馆馆员三类 NPC 互动；`sleep` 指令为寝室专属通关指令。

所有拓展指令均绑定对应关卡与房间场景，仅满足前置条件时方可生效。系统需要严格限制指令跨场景滥用，杜绝玩家通过违规指令跳过主线流程，针对每一次无效、违规指令操作，都需要输出清晰易懂的中文失败提示。

### 1.7 干扰物品与房间公告机制

为提升游戏探索真实感与闯关策略性，游戏全地图场景会投放各类干扰物品，同时分关卡更新房间公告。策划文档内场景内容均按照「相对上一关增量更新」规则编写，游戏运行时会自动按关卡累积整合完整场景数据：房间公告保留过往所有关卡的修改内容，场景物品依次投放 1 至当前关卡全部道具，最终生成当前关卡完整的游戏场景。

干扰类物品均可正常拾取，但不属于通关必备道具，核心作用为占用背包负重、误导玩家解谜判断，典型道具包含假金块、过期借阅条、食堂干扰纸条等。主线关键道具包含湿钱、火腿肠、合成三材料、手电筒、归寝单等，直接决定主线流程推进。房间公告承担场景背景说明、解谜线索提示、NPC 功能指引多重作用，覆盖志愿者流程指引、图书馆电子公告、猫学长互动提示等全部场景文案。

### 1.8 图形界面、存档与联机功能

游戏配套可视化图形交互界面，降低命令行操作门槛，适配不熟悉代码指令的玩家独立完成全部关卡。图形界面必须涵盖房间信息展示、可视化指令操作面板、背包及负重实时展示、游戏操作日志输出、熄灯倒计时面板五大核心模块，界面需要兼容游戏全部指令，包含第四关才解锁的喂猫专属指令，全程无需玩家在图形界面与命令行之间切换操作。

游戏支持本地数据存档功能，系统可将玩家当前关卡编号、剩余闯关时长存入数据库，支持后续断点续玩。玩家读取存档后，将回归当前关卡校门起点，游戏倒计时同步恢复为存档记录时长，同时背包物品统一清空，需要玩家重新收集本关全部道具。该设计既能保留玩家关卡进度，又能保证每一关闯关体验完整，避免依托存档降低游戏难度。游戏全部关卡通关完成后，系统关闭存档功能，不再支持进度保存。

项目额外开发网络多人联机模式与账号登录系统，玩家可完成账号注册、登录并进入多人联机房间。系统需要实时同步游戏核心运行状态，针对玩家进出房间、倒计时变动等关键行为进行全局广播，支撑玩家多人协作闯关、旁观对局两种联机玩法。

## 二、非功能性需求

### 2.1 时间与难度控制

游戏核心闯关压力来源于熄灯倒计时，因此全游戏所有操作耗时、各关卡总限时必须严格贴合策划设定，保证游戏难度曲线平稳合理。当倒计时归零，系统需要立即判定当前关卡失败，玩家需重新开启本关挑战。同时规则明确：仅指令执行成功后才会扣除对应时长，无效操作、错误操作不进行计时扣除，避免玩家因误操作受到不必要的惩罚。

| 动作类型 | 耗时 |
|----------|------|
| 进入房间 / 回退上一房间 | 15 秒 |
| 查看房间场景信息 | 10 秒 |
| 拾取物品 | 20 秒 |
| 丢弃物品 | 10 秒 |
| 物品使用 / 材料合成 / 凭证提交 | 25 秒 |
| 与 NPC 对话交互 | 30 秒 |
| 食用任意食物 | 25 秒 |
| 投喂猫学长 | 60 秒 |
| 奶茶拉肚子负面罚时 | 额外 30 秒 |
| 无手电强行闯入断电主楼 | 60 秒 |
| 体育馆门锁密码输入错误 | 30 秒 |
| 寝室智能锁密码输入错误 | 60 秒 |

| 关卡 | 单关总限时 |
|------|------------|
| 第一关 | 4 分钟 |
| 第二关 | 5 分钟 |
| 第三关 | 7 分钟 |
| 第四关 | 9 分钟 |
| 第五关 | 12 分钟 |

### 2.2 核心机制的一致性与不可绕过性

游戏核心规则无任何特例豁免场景，保障五关流程标准化、可测试、可验收。具体硬性规则如下：博学主楼仅第三、四关处于断电状态，无手电筒无法准入，第五关主楼恢复正常供电；西楼困锁机制唯一破解方式为合成并使用锤子，不支持任何道具、指令绕过解谜；第五关寝室仅 20000527 为有效解锁密码，其余数字均为干扰内容；第二关及之后关卡，未完成归寝单提交无法进入寝室就寝，提交错误物品直接判负；前三关全程隐藏 `feed` 投喂指令，指令注册层、游戏帮助面板、图形界面均无该功能入口，第四关才完整解锁对应功能。

### 2.3 魔法饼干、负重与玩家自主选择规则

魔法饼干兼具时长补给与负重扩容双重效果，为避免玩家利用道具无限刷取时长破坏游戏平衡，系统增设使用限制：单关卡内仅首次食用魔法饼干可补充 300 秒闯关时长，同一关卡重复食用仅增加角色负重，不再提供时长加成。角色负重上限仅可通过魔法饼干永久提升，其余所有食物、干扰道具均无法改动负重数值。

火腿肠在猫学长登场前仅为普通食用道具，猫学长解锁后，玩家可自主选择食用火腿肠补充基础耗时，或是留存火腿肠投喂 NPC 换取魔法饼干，系统不做强制干预。地图拾取饼干与喂猫兑换饼干效果互通，两种获取方式并行，为第四、五关玩家提供多元化闯关策略选择。

### 2.4 界面提示与工程代码质量要求

游戏除满足基础游玩功能外，还需兼顾运维可读性与后期可维护性。所有异常操作场景，包括无权限进入房间、关键道具缺失、输入未知指令、前置条件未达标等，均需要展示通俗易懂的中文文字提示，禁止无响应静默失败、禁止直接输出后端代码报错信息。完整单人游戏流程可全程依托图形界面完成，无需依赖命令行辅助操作。

工程开发层面，项目支持 Maven 一键构建打包，代码格式符合 Checkstyle 代码规范要求，同时依托 JUnit 完成核心业务逻辑单元测试。测试用例必须覆盖关卡切换、喂猫指令解锁、魔法饼干时长加成、存档读档、西楼密室困锁、条件门准入拦截等全部核心规则，确保文档需求均可落地实现，代码逻辑与需求文档完全匹配。

### 2.5 存档与多人模式约束要求

存档功能设计核心原则为「保留关卡进度，不复制角色通关优势」，因此读档仅同步关卡编号与剩余倒计时，玩家回归关卡起点且背包清空。该设计既可以防止玩家反复读档囤积关键道具降低游戏难度，又可以避免玩家重头开启全关卡流程，兼顾游戏公平性与游玩便利性。多人联机模式最低功能要求为：全局倒计时实时同步，玩家进入、退出房间的行为可被所有在线玩家实时感知，保证联机对局状态统一。
