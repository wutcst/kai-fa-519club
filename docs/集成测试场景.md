# T4 集成测试场景说明

> **测试类：** `cn.edu.whut.sept.zuul.integration.GameIntegrationTest`  
> **Issue：** #35 / T4  
> **运行：** `mvn test -Dtest=GameIntegrationTest` 或 `mvn test`

## 场景总览

| 编号 | 场景 | 覆盖模块 | 测试方法 | 预期 |
|------|------|----------|----------|------|
| IT-01 | 第 1 关通关 | LevelManager + LevelTimer + go/take/use/sleep | `integrationLevelOnePassFromGateToSleep` | 大门出发换卡，`sleep` 后进入第 2 关 |
| IT-02 | 超时失败 | LevelTimer + look 扣时 + LevelManager 失败 | `integrationTimeoutFailureViaContinuousCommands` | 连续 `look` 耗尽秒数，状态 `FAILED`、剩余 0 秒 |
| IT-03 | 第 3 关西楼 | E12 黑暗罚时 + E14 困锁 + combine + use | `integrationLevelThreeWestBuildingEscape` | 无手电罚时、合成锤子、`use` 后西楼出口解锁 |
| IT-04 | 第 2 关 submit 与条件门 | E13 条件门 + submit + sleep | `integrationLevelTwoSubmitGatedDoorAndSleep` | 未 submit 无法进寝室；submit 后 `sleep` 进第 3 关 |
| IT-05 | 操作耗时与黑暗罚时 | E11 扣秒 + E12 罚时 | `integrationContinuousMoveAndDarkPenaltyDeductTime` | 连续 `go` 扣 30 秒；第三关无手电额外扣 60 秒 |
| IT-06 | 喂猫与饼干加时 | E5 feed + E7 饼干加时 | `integrationFeedCatThenCookieExtendsTimer` | 喂猫得饼干，食用后倒计时净增 275 秒 |

## 各场景步骤

### IT-01 第 1 关通关

1. 从 `gate` 出发，`go north` ×2 至北楼拾 30 元  
2. `go west` 至超市，`use` 三十元换一卡通  
3. `go north` 至寝室，`sleep`  
4. **预期：** 关卡号变为 2，输出含「恭喜通关」

### IT-02 超时失败

1. 第 1 关起点，计时 240 秒  
2. 循环执行 `look`（每次扣 10 秒）直至计时归零  
3. **预期：** `LevelState.FAILED`，剩余秒数 0，计时器停止

### IT-03 第 3 关西楼

1. 进入第 3 关，无手电 `go north` 触发黑暗罚时并留在 `gate`  
2. 经体育馆取手电，进入西楼被困  
3. 拾取棍/石/绳，`combine` 得锤子，`use` 砸锁  
4. **预期：** `isWestBuildingExitLocked()` 为 false

### IT-04 第 2 关 submit 与条件门

1. 第 2 关：北楼对话领归寝单，超市换一卡通  
2. 持一卡通但未 submit 时 `go north` 进寝室  
3. **预期：** 留在超市，返回条件门拒绝信息  
4. `submit` 归寝单后进寝室 `sleep`  
5. **预期：** 进入第 3 关

### IT-05 操作耗时与黑暗罚时

1. 第 1 关连续两次成功 `go north`，验证扣 `2 × 15` 秒  
2. 进入第 3 关，无手电进入主楼方向  
3. **预期：** 扣黑暗罚时 60 秒且不离开 `gate`

### IT-06 喂猫与饼干加时

1. 第 4 关：食堂取火腿肠，体育馆取手电，至北楼  
2. `feed` 喂猫（扣 60 秒，获得 magic cookie）  
3. `eat magic cookie`（扣 25 秒 + 加 300 秒）  
4. **预期：** 净增 275 秒，本关饼干加时已消耗
