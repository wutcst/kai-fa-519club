UseCommand · SubmitCommand …

NPC · GatedRoom · TeleportRoom
JDBC · Repository / DAO

持久化数据 data/zuul-save.mv.db
用户账号 · 登录会话 · 存档槽
通关记录 · 好友关系 · 关卡进度
