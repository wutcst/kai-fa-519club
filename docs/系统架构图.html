图 4
前后端职责划分
Swing 负责玩法 · Vue 负责数据展示

主前端 · Swing（F7）

  • 房间、背包、命令按钮（含 eat）
  • 距熄灯（23:00）倒计时
  • 五关主玩法交互
  • 单机 → CommandManager
  • 联机 → POST /api/game/command

辅前端 · Vue 3

  • Leaderboard.vue 排行榜
  • SaveManager.vue 存档列表
  • RoomLobby.vue 联机大厅
  • Axios + REST
  • 不承担 go/take/use 操作
Swing 与 Vue 共用 Spring Boot REST 后端 · 规则只在内核实现一份
图 5
联机模式命令时序
计时以服务端 LevelTimer 为准
1
Swing 主前端
玩家操作「向北」→ 命令 go north
2
POST /api/game/command
请求 JSON { "cmd": "go", "arg": "north", "roomId": "...", "playerId": "..." }
3
GameCommandController → GameEngineFacade
CommandManager.executeCommand() → GoCommand → LevelTimer.deduct(15s)
4
JSON 响应 → Swing
roomDescription · remainingSeconds · inventory
